# GeoSweeperサポート

**最終更新日:** 2026年10月4日

GeoSweeperは、204か国の実際の国境線に沿って切り取られたボードでプレイする、クラシックなマインスイーパーです。加えて、2つの世界があります。好きなボードサイズと難易度で遊べる自由形式のマインスイーパーであるClassicモードと、終わりのない登坂に挑むInfinite Towerです。完全にオフラインで動作し、進行状況はデバイス上にのみ保存され、アカウントも個人情報も一切必要ありません — 詳細は[プライバシーポリシー](../../privacy/ja/)をご覧ください。

## よくある質問

### 収録内容

GeoSweeperには3つの世界があります。**Globe**は204か国で構成され、それぞれの国の実際の輪郭に沿って切り取られたマインスイーパーのボードで、サイズに基づく4つの階層 — **Beginner**、**Intermediate**、**Expert**、**Mega** — にグループ分けされています。**Classic**は2つ目の世界です。シンプルな長方形のボードで遊ぶ自由形式のマインスイーパーで、ボードのサイズを自分で選び、**Easy**から**Insane**までの5つの難易度のいずれかを選びます。終了したゲームの**History**も残ります。**Infinite Tower**は、3つ目の独立した世界で、地図のない、一段ずつ登っていく終わりのない挑戦です。Settingsでは、ボードテーマ(**Country themes**、**Classic**、**Neon**)、地図のスタイル(**Globe**または**Flat**)、爆発エフェクト(**Shockwave**、**Embers**、**Chain**)、爆発音、サウンドと触覚、表示言語を設定できます。**Your Record**では、階層別・国別に勝敗、勝率、ベストタイムを確認できます。**Countries**では、完了済みまたは未完了でフィルターしながら、すべての国を閲覧・検索できます。

### 対応デバイスと画面の向き

GeoSweeperはiOS 17以降が必要で、iPhoneとiPadの両方、縦向き・横向きいずれでも動作します。

### 料金はいくらですか?

3つの世界にはそれぞれ独自の無料枠があります。Beginnerを含むどの階層でも、最初にプレイする10か国は無料です。一度プレイした国は、この無料枠を使い切った後もずっと再プレイ可能なままです。Classicモードも同じように10ゲーム無料でプレイできます。Infinite Towerの最初の10段も無料です。これらのポイントを超える部分はすべて、それぞれ独立した一回限りの購入です — GeoSweeperには自動更新や自動課金は一切なく、購入していないものがAppleの購入確認なしに課金されることもありません。

### 残りの地図の解放について

**All Countries**は、単一の一回限りの購入で、すべての国のIntermediate、Expert、Mega階層を永続的に解放します。更新されず、サブスクリプションでもありません — 一度購入すればあなたのものです。

### Classicモードの解放について

**Classic Lifetime**は、単一の一回限りの購入で、無料の10ゲームを使い切った後、Classicゲームを無制限に遊べるよう永続的に解放します。更新されず、サブスクリプションでもありません — 一度購入すればあなたのものです。

### Infinite Towerの解放について

**Infinite Tower Lifetime**は、単一の一回限りの購入で、10段目を超えて登ることを永続的に解放します。更新されず、サブスクリプションでもありません — 一度購入すれば永久にあなたのものです。GeoSweeperはTowerに限らず、いかなるサブスクリプションも提供していません。

### 購入したのにまだロックされている

Settingsで**Restore Purchases**をタップしてください。これにより、あなたのApple Accountが所有しているものが再確認され、再び解放されます — 無料で、再インストール後も含め、同じApple Accountでサインインしているどのデバイスでも機能します。それでもロックされたままの場合は、お使いのデバイスとどの購入だったかを添えてご連絡ください。

### 再インストールすると購入したものはリセットされますか?

いいえ。購入はアプリのローカルファイルではなく、あなたのApple Accountに紐づいているため、Restore Purchasesを使えば新規インストールでも復元されます。一方、国ごとの記録とInfinite Towerの進行状況はデバイスにローカルなものなので、再インストールするとそれらは消去されます。これはどんなファイルを削除しても同じことです。

### 返金について

App Store経由の購入の返金はすべてAppleが対応しており、GeoSweeperが直接返金する方法はありません。[reportaproblem.apple.com](https://reportaproblem.apple.com)からリクエストしてください。

### プライバシーについて

GeoSweeperは、設定と進行状況をあなたのデバイス上にのみ保存します。アカウント、広告、分析、いかなるサードパーティコードもありません。詳細は[プライバシーポリシー](../../privacy/ja/)をご覧ください。

### お子様や教室での利用について

GeoSweeperは一般層向けの年齢レーティングを取得しています。アプリ内には、チャット、共有機能、ソーシャル機能、広告のいずれもありません。

### 国の形と難易度の仕組みについて

各国のボードは、その国の実際の輪郭から生成されます — マスは陸地がある場所にのみ存在し、海岸線がボードの形を決め、最も小さな島々はすでに開いた状態で景観として表示されます。階層(Beginner、Intermediate、Expert、Mega)は国の大きさによって決まり、あなたが選ぶものではありません。ほぼすべてのボードはソルバーによって論理だけでクリア可能であることが検証されており、最初のタップは常に安全な場所に当たります — その下に地雷が待っていることはありません。

### Classicモードの仕組みについて

Classicは、あなたの好きなように遊べるシンプルなマインスイーパーです。ボードの幅と高さを自分で設定し、**Easy**、**Medium**、**Hard**、**Expert**、**Insane**の5つの難易度のいずれかを選びます。これによってボードの地雷の密度が決まります。地図と同様に、すべてのボードは論理だけでクリア可能なように作られており、最初のタップは常に安全な場所に当たります。**History**には、終了した各ゲームのサイズ、難易度、タイム、結果が記録され、デバイス上にのみ保存されます。最初の10回のClassicゲームは無料です。それ以降は**Classic Lifetime**で無制限にプレイできるようになります。

### Infinite Towerの実際の仕組みについて

ある段のすべての安全なマスを開けると、その上の段が解放されます。地雷を踏むと、その段は最初からやり直しになります。100段目以降では、地雷を踏むと現在の段の先頭に戻るだけでなく、さらに数段下まで戻されます — これは気づかないまま起こりやすいため、ここで明記しています。登るほど地雷の密度は上がります。あなたの段、ビューポート、クリア済みの段は各段のクリア後に保存されるため、アプリを閉じてもすでに積み上げた進行状況が失われることはありません。

### データはどこへ行くのか

現在解いている最中のボード — すべてのマスとフラグ — は、3つの世界すべてにおいて、そのボードにいる間だけメモリ上に存在します。ボードの途中でアプリを閉じると、そのボードは永久に消えます。記録またはClassicの履歴に保存されるのは、完了した勝利または敗北のみです。取り消し機能や途中のオートセーブは、あえて用意されていません。

### 設定とアクセシビリティについて

サウンドと触覚は、Settings内でそれぞれ独立したスイッチを持っており、デバイスのサイレントスイッチやReduce Motion設定とは独立しています。ボードテーマ、爆発エフェクト、爆発音はすべて見た目だけのもので、マスの下にあるものを変えることはありません。アプリ内の言語選択は、意図的にデバイスのシステム言語とは切り離されています — 一度選択すれば、その後スマートフォンの言語を変更しても、GeoSweeperの言語はそのままです。

### 再インストールとデータの消失について

GeoSweeperを削除すると、そのデバイス上の設定、国ごとの記録、Classicモードの履歴、Infinite Towerの進行状況が削除されます — その後復元できるサーバー上のコピーはありません。購入は例外で、あなたのApple Accountに紐づいているため、再インストールの有無にかかわらず、そのアカウントでサインインしたどのデバイスでも**Restore Purchases**で復元されます。
