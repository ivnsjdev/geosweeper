# GeoSweeper

GeoSweeper puts classic Minesweeper on a map of the world: every one of 204 countries is a
board cut to that country's real outline, sorted into four tiers by size. There is also a
second world, Infinite Tower, an endless climb with no map at all. GeoSweeper plays fully
offline — there is no sign-in, no ads, and nothing about how you play is sent anywhere.
